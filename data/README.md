# Data

The two datasets come from a university module and are **not included** in this repository.
Place them here before running the scripts:

- `measurements.csv`: 208 rows, 60 numeric predictors (`V1`-`V60`) and a `Class` column (`M` = Mouse, `R` = Raccoon)
- `time-series.csv`: 24,000 rows, a period label column plus eight related series (`V2`-`V9`); the analysis uses `V4`
